ہفتہ وار کھانا پلانر — انسٹال ایبل PWA

فائلیں:
- index.html: ایپ
- manifest.webmanifest: PWA کی شناخت اور آئیکنز
- sw.js: آف لائن کیش اور سروس ورکر
- icons/: ایپ آئیکنز

انسٹال کرنے کا طریقہ:
1) پورا فولڈر کسی HTTPS ویب ہوسٹنگ پر اپ لوڈ کریں (مثلاً اپنی ویب سائٹ یا GitHub Pages/Netlify)۔
2) موبائل پر Chrome میں اس HTTPS لنک کو کھولیں۔
3) Install بٹن یا Chrome کے مینو میں Install app منتخب کریں۔
4) پہلی مرتبہ انٹرنیٹ کے ساتھ ایپ کھولیں تاکہ ضروری فائلیں کیش ہو جائیں۔

اہم:
- صرف index.html کو موبائل میں فائل کی طرح کھولنے سے PWA انسٹال نہیں ہوگی؛ HTTPS یا localhost ضروری ہے۔
- Google Fonts کے لیے انٹرنیٹ درکار ہے؛ بنیادی ایپ آف لائن بھی کام کرے گی۔
- ریکارڈ اسی براؤزر/ڈیوائس میں محفوظ ہوتا ہے۔ بیک اپ ٹیب سے JSON بیک اپ بنا کر دوسری ڈیوائس پر بحال کیا جا سکتا ہے۔
- ہر نئے ہفتے دستیاب ڈشز کا سائیکل خودکار طور پر نیا ہو جاتا ہے؛ پرانی ہسٹری محفوظ رہتی ہے۔
- جمعرات کی دال چنا لازمی ڈش کے طور پر نشان زد ہے، مگر اس کے ساتھ دیگر ڈشز بھی منتخب/پکائی جا سکتی ہیں۔
